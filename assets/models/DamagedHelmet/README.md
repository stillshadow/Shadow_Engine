# Damaged Helmet

这是 Khronos glTF Sample Assets 中的 `DamagedHelmet.glb`，用于 Shadow Engine 的最终 PBR 演示。

- 来源：<https://github.com/KhronosGroup/glTF-Sample-Assets>
- 原始下载地址：<https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/DamagedHelmet/glTF-Binary/DamagedHelmet.glb>
- 许可证：模型转换由 ctxwing 以 CC BY 4.0 发布；原始模型作者 theblueturtle_ 的早期版本标注为 CC BY-NC 4.0。

该 GLB 将 base color、normal、metallic-roughness 等纹理嵌入文件，启动时会被 `AssetManager` 自动发现，不需要额外配置贴图路径。
