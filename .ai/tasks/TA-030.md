# TA-030 Toggle the complete editor overlay

## Scope

- add a single global editor UI visibility state;
- hide/show both editor windows, light markers, and ImGuizmo together;
- provide a visible hide button and a keyboard shortcut that can restore the UI while hidden.

## Acceptance criteria

1. `Tab` toggles the complete editor overlay.
2. Hidden mode removes panels, light visualizations, and object/light Gizmos from the frame.
3. The visible UI provides a button to enter hidden mode.
4. Debug build, CTest, and `git diff --check` pass.
