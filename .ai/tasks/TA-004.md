# TA-004 - Depth-tested 3D material preview scene

## Goal

Replace the single rotating triangle with a small three-dimensional material preview scene whose surfaces occlude correctly and whose world-space normals are directly visible.

## Scope

- Add one resize-aware `D32_FLOAT` Depth Buffer and DSV
- Enable depth testing and depth writes in the Graphics PSO
- Replace the triangle with indexed cube and ground-plane geometry
- Store position and normal attributes in the Vertex Buffer
- Draw the cube and ground as two objects with separate per-frame Constant Buffer slices
- Transform normals into world space and display them as an RGB debug view
- Keep the camera fixed while animating the preview object so the depth result is easy to inspect
- Rename the active shader from the triangle milestone to a material-preview name
- Add an effect-first Chinese course chapter with a concise Unreal Engine mapping

No texture loading, physically based lighting, shadow map, camera controls, imported model, editor UI, or third-party dependency is part of this task.

## Acceptance criteria

1. The Debug build creates a `D32_FLOAT` Depth Buffer matching the current client size.
2. Resize releases and recreates both color and depth targets without a Debug Layer error.
3. One indexed cube and one indexed ground plane render with correct front-to-back occlusion.
4. Each object uses a distinct 256-byte-aligned Constant Buffer slice for every swap-chain frame.
5. The Pixel Shader visualizes interpolated world-space normals as RGB.
6. DXC and MSVC build with warnings treated as errors.
7. Resize, minimize, restore, and graceful close continue to work.
8. The course focuses on depth testing and the visible normal debug result instead of DX12 API memorization.
9. JSON checks, trailing-whitespace checks, and `git diff --check` succeed.

## Validation

- Configure and build with the shared CMake presets.
- Run with the D3D12 Debug Layer enabled and capture the final scene.
- Exercise resize, minimize, restore, and graceful close.
- Inspect two frames to confirm that the cube rotates while the ground remains fixed.
