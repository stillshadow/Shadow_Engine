# TA-028 Split scene editor panel and keep default directional light

## Scope

- split the editor into independent left browser and right inspector windows so the render viewport remains visible;
- show scene lights in a persistent list instead of only a combo box;
- remove the `Add Directional` action because the default Directional Light is always present;
- keep the only Directional Light protected from deletion while allowing its parameters to be edited;
- keep Point and Area add/edit/delete actions available;
- allow a selected Point or Area Light to move with the viewport translation gizmo;
- preserve scene serialization and the existing eight-light limit.

## Acceptance criteria

1. Scene objects and scene lights are each shown once in the left column.
2. The default Directional Light is visible, selectable, and editable without an add button.
3. Point and Area lights can still be added from the left column.
4. The editor remains readable at the existing viewport size through independent left/right windows.
5. A selected Point or Area Light can be translated with `W`; Directional Light does not expose a position gizmo.
6. Debug build, CTest, and `git diff --check` pass.
