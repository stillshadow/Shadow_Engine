# TA-017 - Model-file asset list and source-independent Blender workflow

Status: Done (2026-08-13)

## Goal

Keep DCC source files outside the engine asset contract and make the Editor list imported GLB files rather than their internal primitive keys.

## Acceptance criteria

1. The repository no longer requires an `assets/source` directory or `.blend` files.
2. The Blender add-on accepts an arbitrary texture directory and still exports runtime GLBs to `assets/models`.
3. ImGui shows one entry per discovered GLB file.
4. Adding a selected entry creates all primitives belonging to that GLB and copies their imported material factors.
5. Build, tests, add-on syntax check, runtime smoke, and `git diff --check` pass.

## Validation

- `cmake --build --preset debug`: passed with MSVC `/W4 /WX` and DXC warnings-as-errors.
- `ctest --test-dir build/vscode -C Debug --output-on-failure`: 3/3 passed.
- Blender 5.1 factory-startup add-on import, registration, and unregistration: passed.
- Four-second runtime smoke: passed.
- `git diff --check`: passed with only the existing README line-ending notice.
- A real exported multi-primitive GLB still needs manual visual confirmation in the Editor.
