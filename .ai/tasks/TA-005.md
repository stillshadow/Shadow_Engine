# TA-005 - Directional light and Lambert diffuse

## Goal

Turn the world-normal preview into the first lit material scene by adding one world-space Directional Light and a simple Lambert diffuse response, while keeping the normal debug view available at runtime.

## Scope

- Add per-object base colors to the existing Constant Buffer data
- Add one shared world-space light direction, light color, and ambient strength
- Calculate `NdotL` and Lambert diffuse lighting in the Pixel Shader
- Keep calculations in world space so the rotating cube responds correctly to a stationary light
- Toggle between lit shading and the world-normal debug view with the `N` key
- Update the window title with the debug shortcut
- Add an effect-first Chinese course chapter with an Unreal Engine and material-pipeline mapping

No specular highlight, PBR BRDF, texture, shadow, tone mapping, light editor, camera input, or third-party dependency is part of this task.

## Acceptance criteria

1. The cube and ground render with distinct base colors under one Directional Light.
2. Cube brightness changes as its world-space normals rotate relative to the fixed light direction.
3. Back-facing surfaces receive no direct diffuse light and remain visible through a small ambient term.
4. Pressing `N` switches between lit shading and world-normal RGB without rebuilding the PSO.
5. The depth-tested draw order and resize behavior from TA-004 remain correct.
6. DXC, MSVC, and CMake builds pass with warnings treated as errors.
7. Automated resize, minimize, restore, debug toggle, and graceful close pass.
8. The course explains `dot(N, L)` and its snow-mask relevance without expanding DX12 boilerplate.
9. JSON, trailing-whitespace, and `git diff --check` validation pass.

## Validation

- Configure and build with the shared CMake presets.
- Capture lit frames at different cube orientations.
- Send one `N` key press and capture the normal debug view.
- Exercise resize, minimize, restore, and graceful close.

## Result
