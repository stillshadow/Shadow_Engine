# TA-012 - glTF, textured PBR, IBL, and directional shadows

Status: Done (2026-08-12)

## Goal

Build the rendering foundation required for isolated PBR and multi-pass diagnostic demonstrations.

## Ordered milestones

1. Chapter 10: glTF/GLB mesh loading, reusable mesh assets, and dynamic scene objects.
2. Chapter 11: Base Color, normal, and metallic/roughness textures with UV and tangent data.
3. Chapter 14: HDR environment lighting and split-sum image-based lighting.
4. Chapter 15: directional-light shadow mapping.

Also correct Blender orbit direction before milestone work begins.

## Constraints

- Keep Scene, Asset, Editor, and Renderer responsibilities explicit.
- Prefer small named data structures and execution-order comments over generic engine abstractions.
- Each milestone must build, run, expose useful debug controls, and receive a detailed Chinese chapter.
- Advanced reflection reconstruction is outside this foundation task.

## Acceptance criteria

1. Users can load reusable glTF/GLB meshes and add multiple instances to the saved scene.
2. Imported PBR textures and normal maps render with correct color-space handling.
3. Metallic surfaces receive environment reflections through IBL.
4. The directional light casts inspectable shadows into the scene.
5. Existing editor navigation, picking, Gizmo, persistence, and debug views remain usable.
6. MSVC, DXC, focused tests, runtime smoke, and `git diff --check` pass per milestone.
