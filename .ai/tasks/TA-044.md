# TA-044 - Emissive PBR demo, debug quick-cycle, and clearer SSAO

## Scope

- Add a redistributable single-Mesh, single-material PBR asset with an emissive texture for portfolio capture.
- Carry core glTF `emissiveFactor` and `emissiveTexture` through Forward and Deferred HDR lighting so Bloom receives a stable bright source.
- Add an artist-facing emissive strength control that is saved with the scene.
- Add one-key cycling through the core portfolio debug views.
- Correct the current camera-dependent SSAO depth comparison and make contact/cavity response easier to inspect without turning it into a heavy production SSAO system.

## Acceptance criteria

- The CC0 Khronos BoomBox GLB is reproducible from the repository and its source/license are documented.
- Forward and Deferred both show the emissive panel and feed it into Bloom.
- `D` cycles `Lit -> GBuffer Base Color -> GBuffer Normal -> GBuffer Position -> SSAO -> Lit`.
- SSAO uses view-space depth and a wider, deterministic sample pattern; its debug view visibly separates contact/cavity regions from open surfaces.
- Debug build succeeds, all existing tests pass, and the app runs without a D3D12 Debug Layer error log.
