# TA-040 - LearnOpenGL Newport Loft HDRI integration

- Scope: Import LearnOpenGL's `newport_loft.hdr`, convert it to a D3D12 TextureCube, and use one environment resource in the sky and both raster PBR paths.
- Acceptance: the asset is redistributably documented; the scene starts with tuned exposure/Bloom/light values; Forward and Deferred startup remain stable; tutorials describe the data flow and remaining prefilter limitation.
- Validation: Debug build succeeds; all automated tests pass; both raster paths remain alive for at least 12 seconds.
- Known limit: diffuse irradiance and rough specular filtering use readable runtime multi-sampling rather than a precomputed irradiance Cubemap, GGX prefilter mip chain, and BRDF LUT.
