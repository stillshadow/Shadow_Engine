# TA-008 - Material parameter panel

## Goal

Replace keyboard-only material adjustment with a visible panel that teaches the reusable path from UI controls to scene material data and the next-frame Constant Buffer update.

## Scope

- Add a sphere selector
- Add Roughness and Specular Strength sliders with numeric labels
- Add material reset and World Normal debug controls
- Keep `N` as a convenient debug shortcut
- Integrate pinned Dear ImGui v1.92.9 with its official Win32 and DirectX 12 backends
- Keep the existing renderer, scene objects, HLSL, and Constant Buffer path
- Update the practical chapter with a concise recipe for adding future parameters

No editor docking, scene hierarchy, serialization, color picker, or PBR BRDF is part of this task.

## Acceptance criteria

1. The panel visibly controls either material sphere.
2. Roughness and Specular Strength update over `[0, 1]` with numeric feedback.
3. Reset restores the selected sphere and Normal Debug can be toggled from the panel.
4. UI changes modify `SceneObject.material`; the existing per-frame upload path remains unchanged.
5. Resize keeps the panel attached to the right side of the client area.
6. CMake, MSVC, DXC, runtime lifecycle, and `git diff --check` pass.

## Result

- Integrated pinned Dear ImGui v1.92.9 core with its official Win32 and DirectX 12 backends.
- Added a right-side material panel with sphere selection, Roughness and Specular Strength sliders,
  material reset, and World Normal debug controls.
- Kept material values in `SceneObject.material`; the panel changes data before the existing
  `UpdateObjectConstants()` upload in the same frame.
- Preserved `N` as an application-level normal-debug shortcut before ImGui keyboard forwarding.
- Added chapter 6 documenting the old keyboard flow, the panel flow, and the four-layer recipe for
  future material parameters.

## Validation

- `cmake --build build/vscode --config Debug`: passed with MSVC warnings treated as errors.
- Runtime smoke test: the application remained alive for four seconds, created the expected
  `Shadow Engine - Material Parameter Panel` window, and closed normally.
- Automated visual clicking was not completed because the Windows UI control package could not read
  the local Codex installation directory in this session. Manual slider and resize verification remains.
