# TA-020 - Named scene files and imported Ground verification

Status: Done (2026-08-13)

## Goal

Verify the first real textured Ground asset, document where manually prepared runtime assets belong, and support multiple named scene JSON files without adding an asset database.

## Acceptance criteria

1. Ground GLB structure and embedded PBR images are inspected.
2. The Editor lists `assets/scenes/*.scene.json` files.
3. Users can load a selected scene, save the active scene, and save the current state as a new named scene.
4. `Ctrl+S` targets the active scene file, and duplicate names are not overwritten through Save As.
5. Build, tests, runtime smoke, and `git diff --check` pass.

## Validation

- `Ground.glb`: glTF 2.0, one Mesh, one Primitive, one material, three embedded 1024x1024 images.
- Material bindings: Base Color, tangent-space Normal, and Metallic-Roughness are present; Metallic factor is zero.
- `cmake --build --preset debug`: passed with MSVC `/W4 /WX` and DXC warnings-as-errors.
- `ctest --test-dir build/vscode -C Debug --output-on-failure`: 3/3 passed.
- Five-second runtime smoke with Ground and the named-scene UI: passed.
- `git diff --check`: passed with only the existing README line-ending notice.
- Automated visual capture was blocked by local Computer Use filesystem permission; manual debug-view review remains.
