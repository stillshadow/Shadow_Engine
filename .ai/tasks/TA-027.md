# TA-027 Scene lights and editor panel cleanup

## Scope

- remove the duplicate `Current Scene Models` list from the ImGui panel;
- replace the animated directional light with a manually editable scene light;
- add serializable Directional, Point, and Area light entries;
- expose add/select/edit/delete controls in the sidebar;
- evaluate direct PBR lighting from up to eight lights;
- keep the first Directional light as the existing shadow-map caster;
- use a four-sample rectangular approximation for Area lights;
- keep UI strings readable with the default ImGui font;
- document the new light data flow.

## Out of scope

Clustered/tiled lighting, physically precomputed area-light LTC tables, point/area shadow maps, and a hierarchy/ECS.

## Acceptance criteria

1. The top `Scene Object` combo is the only object selection control.
2. Directional light direction is stable and editable instead of time-animated.
3. The sidebar can add and edit Directional, Point, and Area lights.
4. Saving/loading a scene preserves lights; old scene files without `lights` keep a default Directional light.
5. `cmake --build --preset debug`, all CTest targets, and `git diff --check` pass.
