# TA-015 - Correct non-uniform-scale normal and tangent transforms

Status: Done (2026-08-13)

## Goal

Keep geometric normals and the tangent basis correct when a SceneObject uses different X/Y/Z scale values.

## Implementation

1. Add a testable inverse-transpose normal-matrix helper.
2. Upload the normal matrix in ObjectConstants with matching C++/HLSL layout.
3. Transform normals with the normal matrix; transform tangents with the model matrix and re-orthogonalize them.
4. Add a focused math test and update the technical-art guide.

## Acceptance criteria

1. A transformed normal remains perpendicular to transformed surface tangents under rotation and non-uniform scale.
2. C++ and HLSL constant layouts compile with warnings as errors.
3. Existing serializer/picking tests and the new transform test pass.
4. Runtime smoke and `git diff --check` pass.

## Validation
