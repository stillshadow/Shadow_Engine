# TA-010 - Scene editor structure and persistence

## Goal

Make the code easier to extend by separating editable scene data from DX12 rendering, then add in-view
transform manipulation and persistent scene parameters.

## Scope

- Add DX12-independent Scene and SceneObject data.
- Add an EditorLayer with object selection, Transform/PBR Inspector, and viewport Gizmo.
- Support W/E/R move, rotate, and scale operations.
- Save and load Transform and PBR material parameters as readable JSON.
- Load the saved scene at startup and expose save, reload, and restore-default commands.
- Add round-trip serialization validation and a detailed Chinese chapter.

Ray picking, dynamic object creation, hierarchy, undo/redo, and autosave are outside this task.

## Acceptance criteria

1. Renderer no longer owns editable SceneObject or material state.
2. All three scene objects can be selected and edited by numeric Transform controls and a viewport Gizmo.
3. Ctrl+S and the Save button persist Transform and PBR parameters; the next launch loads them.
4. Invalid/missing scene files safely preserve defaults.
5. MSVC, DXC, serialization round trip, runtime smoke, and `git diff --check` pass.

## Result

- Moved editable Transform, mesh identity, and PBR material data into a DX12-independent `Scene`.
- Added `EditorLayer` for selection, numeric Inspector controls, debug views, dirty state, and viewport
  ImGuizmo move/rotate/scale controls.
- Added JSON save, reload, default restore, first-run creation, and startup load through
  `SceneSerializer`; the local working scene is ignored by Git.
- Reduced `D3D12Renderer` to reading Scene data, mapping MeshType to geometry ranges, uploading constants,
  and issuing Draw Calls.
- Added a CTest round-trip test and detailed Chinese chapter 8.

## Validation

- CMake configure and Debug build passed with pinned ImGuizmo and nlohmann/json dependencies.
- MSVC `/W4 /WX` project compilation and both DXC Shader stages passed.
- `SceneSerializerRoundTrip` passed, including modified position, rotation, scale, roughness, and metallic.
- Runtime remained alive for five seconds, created `assets/scenes/current.scene.json`, and exited normally
  with code 0. The generated JSON was inspected and contains readable expected default values.
- Automated Gizmo clicking was not available because the Windows UI control package could not read the
  local Codex installation directory; manual W/E/R interaction remains the final visual check.
