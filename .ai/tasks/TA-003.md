# TA-003 - Constant Buffer and MVP transforms

## Goal

Move the triangle from hard-coded clip-space coordinates into a Model/View/Projection transform pipeline driven by a per-frame Constant Buffer.

## Scope

- Add one `b0` Constant Buffer to the Vertex Shader
- Extend the Root Signature with a Vertex-Shader-visible root CBV
- Allocate one 256-byte-aligned Constant Buffer slice per swap-chain frame
- Keep the Upload Heap persistently mapped and update only the safe current-frame slice
- Build Model, View, and Perspective Projection matrices with DirectXMath
- Animate a three-dimensional triangle rotation
- Keep viewport aspect changes correct after Resize
- Add concise Chinese comments around coordinate conventions, matrix upload, and frame safety
- Add the first numbered technical-art course chapter with an Unreal Engine mapping

No camera input, scene graph, depth buffer, texture, Descriptor Heap CBV, or generic buffer abstraction is part of this task.

## Acceptance criteria

1. DXC compiles the updated `VSMain` and existing `PSMain` with strict warnings.
2. The Root Signature and HLSL register binding both use `b0`.
3. Each back buffer writes to a distinct 256-byte-aligned Constant Buffer slice.
4. The triangle visibly rotates in perspective rather than remaining in clip space.
5. Resize, minimize, restore, and graceful close continue to work.
6. MSVC C++20 UTF-8 `/W4 /WX` compilation succeeds.
7. The course explains coordinate spaces and MVP without expanding DX12 boilerplate.
8. `git diff --check` succeeds.

## Validation

- Compile both HLSL entry points with Windows SDK DXC.
- Compile and link with the installed Visual Studio 2022 MSVC toolchain while CMake remains unavailable.
- Capture two frames at different times and verify that the triangle silhouette changes.
- Automate Resize, minimize, restore, and graceful close.
