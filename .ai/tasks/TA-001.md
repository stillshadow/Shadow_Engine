# TA-001 - Bootstrap the D3D12 renderer

## Goal

Create a minimal, understandable Win32 and Direct3D 12 application that owns the rendering lifecycle required by later HLSL lessons.

## Scope

- Native Win32 window and non-blocking message loop
- D3D12 device with Debug Layer in Debug builds
- Direct command queue and command list
- Three-buffer flip-discard swap chain
- RTV descriptor heap and back-buffer render targets
- Per-frame command allocators and fence synchronization
- Animated clear color
- Correct minimized-window and resize handling
- CMake build definition and concise setup documentation

No programmable graphics pipeline, HLSL shader, geometry, editor UI, or third-party dependency is part of this task.

## Acceptance criteria

1. A Debug x64 build compiles without project warnings.
2. The application opens a 1280 x 720 client area and continuously presents an animated clear color.
3. Resizing recreates all back buffers without Debug Layer errors.
4. Minimizing and restoring does not call `ResizeBuffers` with zero dimensions or crash.
5. Closing the window waits for outstanding GPU work and releases the fence event.
6. `git diff --check` succeeds.

## Validation

- Configure and build with CMake when available.
- Until CMake is installed, compile the same sources with the installed Visual Studio 2022 MSVC toolchain as an additional source-level verification.
- Manually run the Debug executable and exercise resize, minimize, restore, and close.

## Result

Completed on 2026-08-09.

- MSVC 14.44 compiled and linked the Debug executable with C++20, `/W4`, and `/WX`.
- The executable remained live while presenting its animated clear color.
- Automated window interaction passed resize, minimize, and restore without early exit.
- A posted `WM_CLOSE` produced a graceful process exit with code 0.
- CMake configure was not run because CMake is not installed or available on `PATH`.
