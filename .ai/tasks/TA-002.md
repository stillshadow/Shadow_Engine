# TA-002 - Draw the first HLSL triangle

## Goal

Extend the clear-only D3D12 foundation into the first programmable graphics pipeline and render a vertex-colored triangle with HLSL 6 shaders compiled by DXC.

## Scope

- Compile one HLSL source into Vertex Shader and Pixel Shader bytecode with DXC
- Load compiled shader bytecode relative to the executable
- Create an empty Root Signature for a shader that uses no external resources
- Create a Graphics Pipeline State Object
- Define a position/color input layout
- Upload three vertices and create a Vertex Buffer View
- Set viewport, scissor, primitive topology, and draw one triangle
- Keep all non-obvious teaching comments in Chinese
- Add a simplified, progressive Chinese course chapter for the triangle milestone

No constant buffer, transformation matrix, index buffer, texture, depth buffer, camera, or editor UI is part of this task.

## Acceptance criteria

1. DXC compiles `VSMain` as Shader Model 6 Vertex Shader and `PSMain` as Shader Model 6 Pixel Shader without warnings.
2. The Debug x64 executable compiles with C++20, UTF-8, `/W4`, and `/WX`.
3. The window displays one interpolated vertex-colored triangle over the existing animated clear color.
4. Resize, minimize, restore, and graceful close continue to work.
5. D3D12 Debug Layer does not terminate the process during the automated runtime path.
6. The first chapter is replaced with the agreed simple course format and the second chapter follows the same format.
7. `git diff --check` succeeds.

## Validation

- Compile `Triangle.hlsl` with the installed Windows SDK DXC.
- Compile and link all C++ sources with the installed Visual Studio 2022 MSVC toolchain while CMake remains unavailable.
- Run the executable and automate resize, minimize, restore, and graceful close.
- Capture or inspect the rendered window to verify that the triangle, rather than only the clear color, is visible.

## Result

Completed on 2026-08-10.

- Windows SDK 10.0.26100 DXC compiled `VSMain` as `vs_6_0` and `PSMain` as `ps_6_0` with strict warnings and embedded debug information.
- MSVC 14.44 compiled and linked the Debug executable with C++20, UTF-8, `/W4`, and `/WX`.
- Runtime automation passed resize, minimize, restore, and graceful close with exit code 0.
- The captured window visibly contains a red/green/blue triangle with smooth interpolated interior colors over the animated clear color.
- The original encyclopedia-style first chapter was replaced, and both course chapters follow the simplified progressive format.
- CMake configure remains unverified because CMake is not installed or available on `PATH`.
