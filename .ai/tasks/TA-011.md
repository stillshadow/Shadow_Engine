# TA-011 - Editor camera and viewport picking

## Goal

Allow the learner to navigate the material scene and select objects directly in the viewport without
coupling camera or picking logic back into the DX12 renderer.

## Scope

- Add a Blender-style orbit EditorCamera with MMB orbit, Shift+MMB pan, wheel dolly, and F focus.
- Feed the same dynamic View/Projection matrices to Gizmo, picking, and rendering.
- Convert viewport mouse coordinates into a world ray and select the nearest intersected object.
- Use local unit-sphere and bounded-ground tests that respect each object's Model Matrix.
- Give ImGui and ImGuizmo priority over scene picking.
- Add picking validation and a detailed Chinese chapter.

Free-fly WASD navigation, triangle-level mesh picking, multi-select, and camera persistence are outside
this task.

## Result

- Added `EditorCamera` with orbit/pan/dolly/focus behavior and moved camera matrix ownership out of the
  renderer.
- Added `ScenePicking` using DirectX unprojection, inverse Model transforms, local sphere/ground
  intersection, and nearest-world-hit selection.
- Updated PBR cameraPosition from the inverse dynamic View Matrix so view-dependent lighting remains
  correct while navigating.
- Added viewport control hints, a projected-sphere picking test, and chapter 9.

## Validation

- Debug build passed with project `/W4 /WX` and both DXC stages.
- `SceneSerializerRoundTrip` and `ScenePickingProjectedSphere` both passed through CTest.
- Runtime remained alive for five seconds and exited normally with code 0.
- Automated mouse interaction remained blocked by the local Codex installation-directory permission;
  MMB/Shift+MMB/wheel/F and live click selection require manual visual confirmation.
