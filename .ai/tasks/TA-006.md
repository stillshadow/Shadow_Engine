# TA-006 - Material preview sphere and view-dependent specular

## Goal

Replace the hard-normal cube with a smooth procedural material-preview sphere and add a view-dependent Blinn-Phong highlight that introduces the `N`, `L`, `V`, and `H` vectors needed for the next PBR milestone.

## Scope

- Generate one indexed UV sphere at initialization without a third-party mesh library
- Keep the indexed ground plane and depth-tested two-object draw path
- Pass world position and world normal from Vertex Shader to Pixel Shader
- Add camera world position, roughness, and specular strength to per-object constants
- Calculate a normalized view direction and Blinn half vector in the Pixel Shader
- Map teaching roughness to a Blinn-Phong exponent and add a view-dependent highlight
- Slowly orbit the Directional Light so the highlight movement is visible on the stationary sphere
- Preserve the `N` world-normal debug toggle
- Add an effect-first Chinese course chapter and an Unreal Engine/PBR mapping

No Cook-Torrance BRDF, Metallic workflow, texture, IBL, shadow, tone mapping, mesh import, camera controls, or third-party dependency is part of this task.

## Acceptance criteria

1. A smooth indexed UV sphere replaces the cube while the ground remains visible and depth-tested.
2. The sphere uses shared positions with smooth outward normals; the ground retains a flat upward normal.
3. Pixel Shader receives world position and computes `V = normalize(CameraPosition - WorldPosition)`.
4. A visible specular highlight changes as the Directional Light moves, while rough ground receives a much weaker highlight.
5. `N` still switches to the world-normal RGB view without rebuilding the PSO.
6. Root Constant Buffer data remains within one 256-byte-aligned slice per object.
7. CMake, MSVC, and DXC builds pass with warnings treated as errors.
8. Resize, minimize, restore, normal toggle, and graceful close pass with exit code 0.
9. The course clearly labels Blinn-Phong as a learning bridge rather than the final PBR model.
10. JSON, trailing-whitespace, and `git diff --check` validation pass.

## Validation

- Configure and build with the shared CMake presets.
- Capture two lit frames far enough apart to show highlight movement.
- Capture the world-normal debug view after one `N` key press.
- Exercise resize, minimize, restore, and graceful close.
