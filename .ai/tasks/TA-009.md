# TA-009 - Cook-Torrance PBR foundation

## Goal

Replace the teaching Blinn-Phong material with a metallic/roughness Cook-Torrance BRDF that maps
directly to the material concepts used by technical artists and Unreal Engine.

## Scope

- Replace Specular Strength with Metallic in CPU material data, Constant Buffer data, HLSL, and ImGui.
- Implement GGX normal distribution, Schlick-GGX geometry masking, and Schlick Fresnel.
- Add Base Color editing and Lit/Base Color/World Normal/Roughness/Metallic debug views.
- Keep the existing directional light, scene geometry, per-object Constant Buffer path, and `N` shortcut.
- Add a detailed Chinese chapter 7 focused on the BRDF and visual meaning rather than DX12 boilerplate.

Image-based lighting, textures, shadows, clear coat, and anisotropy are outside this task.

## Acceptance criteria

1. Both spheres expose Base Color, Metallic, and Roughness in the ImGui panel.
2. Direct lighting uses Cook-Torrance GGX and preserves diffuse/specular energy splitting.
3. Debug views make each core material channel inspectable.
4. CPU and HLSL constant layouts remain explicitly matched and within one 256-byte CB slice.
5. MSVC, DXC, runtime smoke, and `git diff --check` pass.

## Result

- Replaced teaching Blinn-Phong with a Cook-Torrance direct-light BRDF using GGX distribution,
  Schlick-GGX/Smith geometry masking, and Schlick Fresnel.
- Replaced Specular Strength with Metallic and added Base Color editing to the ImGui panel.
- Added Lit, Base Color, World Normal, Roughness, and Metallic debug views; `N` still toggles Lit and
  World Normal.
- Added simple HDR directional radiance, Reinhard tone mapping, and gamma correction.
- Added compile-time Constant Buffer size and field-offset checks plus the detailed Chinese chapter 7.

## Validation

- `cmake --build build/vscode --config Debug`: passed; MSVC, project `/W4 /WX`, and DXC completed.
- Runtime smoke: remained alive for five seconds, created the renderer window, closed through
  `WM_CLOSE`, and exited with code 0.
- `git diff --check`: passed. The trailing-whitespace search returned no matches; its no-match exit code
  made the combined shell invocation report 1 after the successful build and diff check.
- Automated screenshot interaction remains unavailable because the Windows UI control package cannot
  access the local Codex installation directory in this session.
