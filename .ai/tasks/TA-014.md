# TA-014 - Consolidate lessons into a technical-art engine guide

Status: Done (2026-08-13)

## Goal

Remove the chronological milestone lessons and replace them with one code-linked guide that teaches only the
engine knowledge a technical artist needs to navigate, modify, debug, and present Shadow Engine.

## Deliverables

1. Delete all existing numbered course Markdown files under `docs/`.
2. Add one consolidated technical-art engine guide based on the current repository.
3. Cover architecture, startup, frame flow, assets, material data, HLSL, IBL, shadows, editor, persistence,
   practical modification paths, debugging, DX12 essentials, limitations, and interview presentation.
4. Replace the README lesson list with one canonical guide link.

## Constraints

- Do not change runtime behavior.
- Teach current implementation facts, not an idealized generic engine.
- Clearly mark must-master, read-only awareness, and optional graphics-programmer depth.
- Keep Chinese explanations and original code/API identifiers.

## Acceptance criteria

1. `docs/` contains only the consolidated guide.
2. Every important code path links to a current file/function.
3. The guide provides a recommended reading and hands-on sequence before scene dressing.
4. README link and `git diff --check` pass.
