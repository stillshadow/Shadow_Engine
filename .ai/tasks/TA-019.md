# TA-019 - Remove multi-mesh scene architecture

Status: Done (2026-08-13)

## Goal

Restore the simpler one-Mesh, one-material, one-SceneObject asset contract so portfolio work stays focused on rendering and wet-surface effects.

## Preserve

- Runtime GLBs under `assets/models`.
- Startup GLB discovery.
- The ImGui imported-model file list.
- Blender arbitrary texture-folder selection and one-click GLB export.

## Remove

- `ScenePart` and version-2 scene persistence.
- glTF node-transform baking and multi-Mesh grouping as one editable object.
- Per-part material UI and multi-selection Blender export.
