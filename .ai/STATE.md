- Current project state: TA-043 is complete. Forward and Deferred use standard CPU-precomputed Split-Sum IBL and share Directional, Point, Area, and Spot PBR lighting. The first Directional and first Point light cast shadows. The engine also has back-face culling, sorted Forward transparency fallback, selected-object stencil outline, optional Forward 4x MSAA resolve, real GPU instance batching, and a Geometry Shader normal debug view.
- Changes: Added Irradiance/Prefilter/BRDF LUT resources; Spot Light and Point Shadow; D24S8 stencil selection; opacity editing and mixed Deferred/Forward transparency; Forward-only MSAA; per-frame StructuredBuffer transforms with consecutive identical-material batching; and optional Geometry Shader triangle normals. ImGui now owns mouse input through `WantCaptureMouse` plus current-frame hover checks, preventing viewport click-through; Tab clears selection/highlight while retaining the full editor-overlay toggle. Ground outlines now depth-test against foreground meshes. The editor can create built-in Sphere, Cube, and Plane objects directly in the current Scene; built-in Cube/Plane meshes are generated by AssetManager. Selected Point lights now visualize their real world-space `range` with three projected great circles. Gizmo interaction no longer toggles from stale `WantCaptureMouse` state while the pointer crosses its axes. TA-044 adds the CC0 BoomBox portfolio asset, core glTF Emissive import, per-object Emissive Strength, Forward and fourth-GBuffer Deferred emissive HDR output, a `D` portfolio debug cycle, and view-space 16-sample SSAO with single strength mixing. The default scene is tuned for visible Bloom and SSAO. The selected outline and Geometry Normals debug lines now use scale-compensated world lengths, and glTF meshes are converted from right-handed to the engine's left-handed convention so the BoomBox antenna and `PLAY` label are no longer X-mirrored. A separate ImGui `Hide Viewport Overlays` switch now hides Gizmo, selection outline, light visuals, and normal debug lines while leaving parameter panels and selection state available. No new course chapters were created per user request.
- Light editing now extracts Area/Spot emission direction directly from the manipulated gizmo matrix, so local X/Y/Z rotation changes persist instead of being reconstructed through an unstable Euler-angle round trip. Light picking accepts the full Area rectangle and Spot cone in screen space, and selected lights can be deleted from either inspector or list, or with `Delete`; selection is revalidated after removal. Area lighting now uses a 4x4 stratified rectangle sample with one-sided emitter cosine weighting in both Forward and Deferred shaders, replacing the visibly separated four-corner point approximation.
